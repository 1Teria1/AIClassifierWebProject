# AI Support Classifier

> Автоматическая классификация обращений в службу поддержки на основе RuBERT

## 📋 О проекте

**AI Support Classifier** — это веб-сервис для автоматической сортировки обращений в службу поддержки. Сервис анализирует текст сообщения и определяет:

- **Категорию обращения** (Оплата, Доставка, Техническая проблема, Вопрос по товару, Спам)
- **Приоритет** (Критический, Высокий, Средний, Низкий)
- **Уверенность модели** (по каждому параметру)
- **Распределение вероятностей** (массив уверенностей модели в каждом варианте)

### Зачем это нужно?

В крупных компаниях ежедневно поступают тысячи обращений. Ручная сортировка занимает часы работы сотрудников. Наш сервис автоматизирует этот процесс, сокращая время реакции на критичные запросы в 5-10 раз.

### 🧠 Используемые технологии

| Компонент | Технология |
|-----------|------------|
| ML-модель | RuBERT (DeepPavlov base) + Логистическая регрессия |
| Фреймворк | PyTorch + transformers|
| API | RestAPI на Flask |
| Интерфейс | HTML/CSS/JavaScript |

## 🚀 Быстрый старт

### Требования

- Python 3.9 или выше
- 8+ GB RAM (16 GB рекомендуется)
- GPU (рекомендуется, но не обязательно)
- 1+ GB свободного места на диске

### Установка и запуск
1. Скачать (и распаковать при необходимости) файлы: main.py, TransformerInterface.py и index.html
2. Скачать веса модели (файл model.pt) из другого источника и переместить в папку с остальными файлами
3. Установить библиотек из requirements.txt
4. Запустить файл main.py (первый запуск может занять несколько минут)
5. Перейти по ссылке в терминале на локальный хост
6. Готово! Сайт открыт и готов к использованию
